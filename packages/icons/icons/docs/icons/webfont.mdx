## Installation

```
yarn add @axioledger/icons-webfont
```

or

```
npm install @axioledger/icons-webfont
```

or

```
pnpm install @axioledger/icons-webfont
```

or just [download from GitHub](https://github.com/axioledger/axqdesign-icons/releases).

### CDN

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@axioledger/icons-webfont@$ICONS_VERSION/dist/axqdesign-icons.min.css">
```

## Usage

### HTML

```html
<i class="ti ti-brand-axqdesign"></i>
```

### CSS

```css
content: 'ec8f';
```


### SCSS

```scss
content: $ti-icon-brand-axqdesign;
```
