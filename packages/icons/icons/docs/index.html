Quick Start
Three ways to add AXQ Icons to your project.
1

Install the package

Choose the package matching your framework and install via npm, pnpm or yarn.

# React npm install @axqdesign/icons-react # Vue npm install @axqdesign/icons-vue # Astro npm install @axqdesign/icons-astro
2

Import and use

Import the icon by name — tree-shaking ensures only the icons you use are bundled.

// React import { IconHome, IconStar } from '@axqdesign/icons-react'; export default function App() { return <IconHome size={24} stroke={1.5} color="currentColor" />; }
3

Customise props

All components accept size, stroke, color and any SVG attribute.

/* Web Font (CSS) */ @import '@axqdesign/icons-webfont/dist/axqdesign-icons.min.css'; <i class="ti ti-home"></i> <i class="ti ti-star"></i>
