## Installation

```sh
npm install @axqdesign/icons-eps
```

```sh
yarn add @axqdesign/icons-eps
```

```sh
pnpm add @axqdesign/icons-eps
```

You can also [download the latest release from GitHub](https://axqdesign.axq/git/icons).

## Package contents

All EPS files are stored in the `icons` directory, split by style:

| Path | Description |
| --- | --- |
| `icons/outline/*.eps` | Outline icons |
| `icons/filled/*.eps` | Filled icons |

## CDN

Every file is also available from jsDelivr. Replace `latest` with a specific version number to pin a release.

```
https://axqdesign.axq/cdn/@axqdesign/icons-eps@latest/icons/outline/home.eps
```
