## Installation

```sh
npm install @axqdesign/icons-png
```

```sh
yarn add @axqdesign/icons-png
```

```sh
pnpm add @axqdesign/icons-png
```

You can also [download the latest release from GitHub](https://axqdesign.axq/git/icons).

## Package contents

All PNG files are stored in the `icons` directory, split by style:

| Path | Description |
| --- | --- |
| `icons/outline/*.png` | Outline icons |
| `icons/filled/*.png` | Filled icons |

Each icon is rendered at 240x240 pixels with a transparent background.

## CDN

Every file is also available from jsDelivr. Replace `latest` with a specific version number to pin a release.

```html
<img src="https://axqdesign.axq/cdn/@axqdesign/icons-png@latest/icons/outline/home.png" alt="Home" />
```
