VNKR UI Library Update Plan

Phân tích gap giữa VNKR UI hiện tại và UKIT (AXQ Design System) — xác định những gì cần thêm, cần sửa, và thứ tự thực hiện.
Files đích: vnkr-tokens.css · vnkr-ui.css · vnkr-ui.js Tham khảo: ukit-reference/assets/css/ · packages/design-system/ Nguyên tắc: Giữ prefix vnkr-* · Vanilla CSS+JS · Không framework
Phân Tích Gap — VNKR vs UKIT
Hạng mục VNKR hiện tại UKIT có Ưu tiên
Dark mode ❌ Không có html.dark {} override toàn bộ tokens P1
Input / Form ❌ Không có class nào Input đầy đủ: label, icon left/right, error state, 3 sizes, focus ring P0
Callout / Alert box ❌ Không có .callout-info/warn/danger/success/purple — border-left 3px P0
Skeleton loading ❌ Không có Pulse animation: text, circle, rect, card skeleton P1
Modal / Dialog ❌ Không có Modal đầy đủ: backdrop blur, dialog, header/body/footer, close btn, bottom sheet P1
Timeline Dùng grid cards — không có line connector .tl-wrap với ::before line + .tl-dot circles P1
Nav header glassmorphism Nền đặc #0A3D62 color-mix(85%, transparent) + backdrop-filter: blur(16px) P2
Focus ring / Accessibility ❌ Không có :focus-visible outline: 2px solid var(--color-border-focus); outline-offset: 2px P0
Toast — dismiss button Chỉ auto-dismiss, không có nút × đóng thủ công Có .dismiss button + .action link trong toast P1
Button — loading state ❌ Không có spinner Spinner @keyframes spin trong button khi disabled P1
data-* variant pattern Dùng class modifier --variant [data-size="large"], [data-state="error"] — sạch hơn với JS P2
Token: spacing đặt tên --sp-1..--sp-20 (không dùng nhiều trong component) --space-1..16 dùng nhất quán trong mọi component P2
Scroll-linked nav tint ❌ Nav luôn đặc màu Nav đổi background khi scroll (JS scroll event) P2

Nguyên Tắc Giữ Nguyên
✅ Prefix vnkr-* Mọi class mới đều dùng prefix — không conflict với Tailwind hay Bootstrap
✅ Vanilla CSS + JS thuần Không thêm thư viện ngoài — không Alpine.js, không jQuery
✅ Màu VNKR bất biến #0A3D62 brand · #E84118 accent · #F0A500 gold — không thay đổi
✅ Be Vietnam Pro Font chính không đổi — UKIT dùng Work Sans nhưng VNKR giữ Be Vietnam Pro
✅ Backward compatible Class cũ không bị xóa — chỉ thêm, không breaking change cho code đang dùng
